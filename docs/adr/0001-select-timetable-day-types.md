# 日種は祝日を含めて自動選択し、判断できない場合は指定を求める

`--day` を省略したバス・地下鉄の時刻表と地下鉄の次発案内では、通常の日種を曜日と日本の祝日カレンダーから選ぶ。適用を確認できた特別ダイヤを優先するが、時刻表に日種のキーが存在するだけでは適用の根拠にしない。必要な情報が不足して適用日種を判断できない場合は、利用者に `--day` の指定を求める。

曜日だけで選ぶ方法は祝日に異なる時刻表を案内するおそれがあり、常に指定を必須にする方法は名前だけで次発案内を得る操作を妨げる。祝日カレンダーを維持する負担を受け入れ、通常は自動選択し、不確かな場合は利用者による指定を求める。利用した日種を表示する。
