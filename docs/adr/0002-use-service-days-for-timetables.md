# 時刻表と次発案内にも午前4時の営業日境界を適用する

バス接近情報、バス・地下鉄の時刻表、地下鉄の次発案内は、午前4時を境界とする営業日で扱う。午前0時から3時台は前の営業日の24時から27時台として検索・表示し、日種もその営業日の開始日を基準に判定する。例えば火曜午前1時は月曜の営業日の25時として扱う。

暦の日付だけで日種を切り替えると、深夜便の時刻と、その便が属するダイヤの日種が食い違う可能性がある。営業日の境界をそろえ、深夜便も同じ基準で案内する。

`subway next` は、対象営業日の残りの予定列車が `--limit` に満たない場合、翌営業日の予定列車も検索する。検索範囲は対象営業日と翌営業日までとし、表示する便の営業日と日種を明示する。終電後でも次に乗れる予定列車を案内し、当日の便と翌営業日の便を取り違えないようにする。

`--day` を指定した場合、その日種は対象営業日だけに適用し、翌営業日は自動判定する。例えば金曜の営業日に `--day weekday` を指定しても、翌営業日に平日ダイヤを引き継がない。翌営業日も、その日の適用が確認できたダイヤで案内する。
