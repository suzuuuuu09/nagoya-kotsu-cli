# 全料金経路を対象とする券種の名前解決

`pass --type` は、対象となる全料金経路の券種名をまとめ、同一名の重複を除いて一度だけ名前解決する。既存の名前解決と同じく、前後の空白を除去してNFKC正規化し、完全一致を優先する。完全一致がなければ部分一致を使い、複数候補は `ambiguous` とする。

解決した同じ券種名で全料金経路を絞り込む。経路ごとに独立して名前解決すると、一つの指定が経路によって大学生・大学院生など別の券種に解決され得るため、採用しない。

## 候補を取得しきれない場合

一部の定期料金データを取得できず券種候補が不完全な場合は、取得済み候補で確認できた完全一致だけを使用する。完全一致がなければ、取得済みの全料金経路を `types: []` で残し、取得失敗を含む `complete: false` と非0の終了コードを返す。

未取得の候補によって検索結果が変わる可能性があるため、部分一致による選択は行わず、`not_found` とも断定しない。

候補が揃っている場合の完全一致・部分一致・未発見・曖昧性の扱いは、通常の名前解決に従う。
