# 座標の欠落・不正で交通施設の解釈を変えない

`location` と `nearby` の基準地点は、座標が欠落・不正な施設も名前解決の候補に残す。同名の市バス停と地下鉄駅があれば `ambiguous` を返し、選択した施設に有効な座標がなければ `invalid_response` を返す。

座標を返せない施設を先に候補から除外すると、藤が丘の地下鉄座標が壊れただけで、種別未指定の藤が丘が同名の市バス停として選ばれ得る。候補の施設と座標の利用可否を分け、データ異常によって利用者の指定を別施設へ読み替えない。名前マスターに施設があるのに座標レコードがない場合も、施設が存在しない `not_found` とは区別する。

座標マスターの同じ完全修飾名は一つの施設として扱い、同じ有効な座標の重複だけを統合する。座標が矛盾・不正なら代表座標を採用しない。異なる座標を別施設として残すと完全修飾名だけでは区別できず、先頭や平均を使うと上流で確認できない代表座標を作ることになるため、このどちらも行わない。
