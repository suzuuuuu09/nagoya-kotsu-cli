# 検索した交通施設の完全修飾名を関連コマンドで再利用する

検索で選んだ交通施設の完全修飾名を、経路・時刻表・停留所情報・駅情報・料金・座標・周辺検索の地点引数へそのまま渡せる共通入力にする。通常名も受理し、コマンドの対象種別と矛盾する完全修飾名は明示的に拒否する。

既存コマンドの入力を変えず文書で使い分けを説明する案では、検索結果をコピーした利用者が未発見エラーになり、Agentにも名前への戻し方を覚えさせる。入力の対応範囲を広げるコストを受け入れ、検索から次の操作まで同じ交通施設を指定できることを優先する。内部IDは受け渡しに使わず、既存JSONの構造はこの決定のために変更しない。

完全修飾名は選択済みの施設を指定する名前として、前後空白除去・NFKC正規化後の完全一致だけで解決する。通常名による探索では部分一致を維持するが、完全修飾名が見つからない場合は未発見とし、似た名前の別施設へ読み替えない。入力の省略への寛容さより、検索で選んだ施設をコマンド間で保つことを優先する。
