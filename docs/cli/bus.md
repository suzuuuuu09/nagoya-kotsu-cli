# 市バス

`nkotsu bus` は、市バスの停留所とのりば、時刻表、接近情報を名前で取得します。

```sh
nkotsu bus stop 上社
nkotsu bus timetable 上社 --pole 4番 --route 上社12 --after 14:00 --limit 10
nkotsu bus live 上社 --route 上社12 --json
nkotsu bus live 上社 --pole 4番 --all
```

## 停留所と時刻表

`bus stop` は、指定した停留所のIDとのりばを表示します。名前は前後の空白を除去してNFKC正規化し、完全一致する候補を優先します。完全一致する候補がなければ部分一致で検索し、候補が複数あれば終了コード3で候補を返します。

時刻表を調べるには、`bus timetable` を使います。`--route` は系統名、`--pole` はのりばで絞り込み、`--after HH:MM` は指定時刻以降の便を表示します。`--limit N` で表示件数を指定できます。存在しない系統・のりばの指定はエラーになりますが、有効な指定で便が0件なら成功として扱います。

## 日種と営業日

日種は、時刻表を分類する運行日の区分です。`--day` には `weekday`、`saturday`、`holiday` を指定できます。省略すると祝日と適用が確認できた特別設定から自動選択します。自動選択できない場合は、`--day` を指定してください。

時刻表の一日は、04:00から翌日の04:00までの営業日として扱います。00〜03時台は前の営業日の24〜27時台に相当するため、`--after` では00:00〜27:59を指定できます。

## 接近情報と通過履歴

`bus live` は、公式サイトの現在位置情報と通過履歴を表示します。取得した位置と履歴を表示する機能であり、停留所への到着時刻は計算しません。通常は、対象停留所を未通過の車両と、対象停留所との位置関係が不明な車両を表示します。`--all` を指定すると通過済みの車両も含めます。どちらの場合も、`--route` と `--pole` の絞り込みを適用します。

現在位置が取得できない場合は、「現在位置情報なし」と最終通過を表示します。通過履歴が示すのは記録された通過地点と時刻であり、取得時点の位置を保証しません。そのため、履歴から現在位置、到着予測、遅延分、GPS座標を推定しません。

サービス設定の取得に失敗した場合は、その失敗をサービス停止として扱いません。

出力形式と部分失敗の扱いは、`nkotsu docs show output` で確認できます。
