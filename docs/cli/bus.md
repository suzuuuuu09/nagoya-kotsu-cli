# 市バス

停留所とのりば、時刻表、接近情報を名前で取得します。

```sh
nkotsu bus stop 上社
nkotsu bus timetable 上社 --pole 4番 --route 上社12 --after 14:00 --limit 10
nkotsu bus live 上社 --route 上社12 --json
nkotsu bus live 上社 --pole 4番 --all
```

`stop` は停留所IDとのりばを表示します。`timetable` の `--route` は系統、`--pole` はのりばを絞り込み、`--after HH:MM` は指定時刻以降、`--limit N` は表示件数を指定します。

`--day` は `weekday` / `saturday` / `holiday`。省略時は祝日と適用を確認できた特別設定から自動選択します。不明な場合は `--day` が必要です。営業日は04:00から翌04:00までで、00〜03時台は24〜27時台として扱います。時刻指定は00:00〜27:59です。

`live` は到着予測ではありません。公式の現在位置情報と通過履歴を表示します。通常は未通過または位置関係不明の車両を対象とし、`--all` は通過済み車両も含めます。系統・のりばの絞り込みは維持します。

現在位置がない場合は「現在位置情報なし」と最終通過を表示します。履歴から現在位置、到着予測、遅延分、GPS座標を推定しません。設定取得に失敗した場合はサービス停止と断定しません。

名前は前後空白を除去してNFKC正規化し、完全一致、部分一致の順で選びます。複数候補は自動選択せず終了コード3で候補を返します。存在しない系統・のりばはエラーですが、有効な指定で便が0件なら成功です。

出力形式と部分失敗は `nkotsu docs show output` を参照してください。
