# 地下鉄

時刻表と、時刻表から算出した次に発車する予定列車を表示します。リアルタイムの列車位置や運行実績ではありません。

```sh
nkotsu subway timetable 藤が丘 --line 東山線
nkotsu subway timetable 藤が丘 --after 14:00 --limit 10
nkotsu subway next 藤が丘 --limit 3
nkotsu subway next 栄 --line 東山線 --direction 藤が丘方面 --json
```

`--line` は路線、`--direction` は方面を指定します。候補が曖昧または指定が存在しない場合は候補を示して終了コード3で終了します。

`--day` は `weekday` / `holiday` / `new-year` / `all-night`。省略時は祝日と適用が確認できた特別設定から自動選択します。特別ダイヤのキーがあるだけでは適用しません。判断できない場合は日種を指定してください。同梱の祝日データは1955〜2027年が対象です。臨時変更すべての自動判定は保証しません。

営業日は04:00から翌04:00までで、00〜03時台を24〜27時台として扱います。`timetable --after HH:MM` と `next --at HH:MM` は00:00〜27:59を指定できます。

`next` は `--at` 省略時に現在時刻を使い、翌営業日まで検索します。`--day` の上書きは最初の営業日にだけ適用します。各便の日付・日種を確認してください。`--limit N` は表示件数で、`next` の既定値は5です。

有効な条件で予定列車が0件なら成功です。翌営業日の取得に失敗した場合も最初の日の予定列車を保持して不完全な結果として返します。

出力形式は `nkotsu docs show output` を参照してください。
