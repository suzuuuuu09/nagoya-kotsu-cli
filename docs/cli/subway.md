# 地下鉄

`nkotsu subway` は、地下鉄の時刻表と、時刻表から算出した次に発車する予定列車を表示します。予定列車は発車予定に基づく案内であり、実際の列車位置や運行実績を示すものではありません。

```sh
nkotsu subway timetable 藤が丘 --line 東山線
nkotsu subway timetable 藤が丘 --after 14:00 --limit 10
nkotsu subway next 藤が丘 --limit 3
nkotsu subway next 栄 --line 東山線 --direction 藤が丘方面 --json
```

## 路線・方面と表示件数

`--line` は路線、`--direction` は方面を指定します。指定が存在しない場合や候補が複数ある場合は、候補を示して終了コード3で終了します。有効な条件で予定列車が0件なら、成功として扱います。

表示する便を絞るには、`subway timetable --after HH:MM` または `subway next --at HH:MM` を使います。`--limit N` は表示件数を指定するオプションで、`next` の既定値は5件です。

## 日種と営業日

日種は、時刻表を分類する運行日の区分です。`--day` には `weekday`、`holiday`、`new-year`、`all-night` を指定できます。省略すると祝日と適用が確認できた特別設定から自動選択します。特別ダイヤのデータが存在するだけでは、そのダイヤを選択しません。

自動選択できない場合は、`--day` を指定してください。同梱の祝日データは1955〜2027年が対象です。臨時変更をすべて自動判定することは保証していません。

時刻表の一日は、04:00から翌日の04:00までの営業日として扱います。00〜03時台は前の営業日の24〜27時台に相当するため、`--after` と `--at` では00:00〜27:59を指定できます。

## 次発の検索範囲と部分失敗

`subway next` は、指定時刻以降の予定列車を翌営業日まで検索します。`--at` を省略すると現在時刻を使います。`--day` による上書きは最初の営業日だけに適用するため、結果に含まれる各便の日付と日種を確認してください。

翌営業日の取得に失敗した場合も、最初の営業日で取得できた予定列車は保持します。ただし、結果は不完全として返します。出力形式と部分失敗の扱いは、`nkotsu docs show output` で確認できます。
