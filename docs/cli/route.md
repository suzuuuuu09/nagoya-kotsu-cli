# 経路検索

出発地から到着地までの経路を検索します。

```sh
nkotsu route 藤が丘 名古屋 --subway
nkotsu route 藤が丘 名古屋 --subway --at 09:00
nkotsu route 藤が丘 名古屋 --subway --at 18:00 --arrive
nkotsu route 藤が丘 名古屋 --subway --via 栄 --details --json
```

名前は前後空白除去とNFKC正規化の後、完全一致、部分一致の順で検索します。完全一致でも複数候補があれば曖昧性エラーです。「藤が丘」は市バス停と地下鉄駅の候補があるため、交通手段や `藤が丘(名古屋市地下鉄)` のような候補名を指定してください。

`--bus` だけなら市バスのみ、`--subway` だけなら地下鉄のみ、両方指定または無指定なら両方が対象です。指定は出発地・到着地・経由地の候補と乗車区間の両方に適用します。`--via` は経由地、`--slow-transfer` はゆっくり乗換、`--details` はのりば・区間運賃などの詳細を表示します。

`--at` は `HH:MM` または `YYYY-MM-DDTHH:MM`。日本時間の暦日時で検索します。`HH:MM` は今日の日付を使い、過去時刻でも翌日へ繰り越しません。例: 10月5日23時に `--at 01:00` を指定すると10月5日01時です。翌日を調べる場合は日付を指定してください。

`--arrive` は指定時刻までに到着する経路を検索します。時刻を省略すると現在時刻を使います。`--first` は始発、`--last` は終発を検索し、両者と `--at` / `--arrive` は同時指定できません。営業日境界を `--at` の日付補完には適用しません。

有効な検索条件で経路が0件なら成功です。乗換回数と乗車区間の数は別の項目です。

出力形式とエラーは `nkotsu docs show output` を参照してください。
