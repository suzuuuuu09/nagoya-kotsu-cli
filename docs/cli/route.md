# 経路検索

`nkotsu route` は、出発地から到着地までの経路を検索します。交通手段、経由地、検索時刻を指定できます。

```sh
nkotsu route 藤が丘 名古屋 --subway
nkotsu route 藤が丘 名古屋 --subway --at 09:00
nkotsu route 藤が丘 名古屋 --subway --at 18:00 --arrive
nkotsu route 藤が丘 名古屋 --subway --via 栄 --details --json
```

## 地点名と交通手段

地点名は前後の空白を除去してNFKC正規化し、完全一致する候補を優先します。完全一致する候補がなければ部分一致で検索します。どちらの場合も、候補が複数あれば曖昧性エラーとして扱い、自動選択しません。

たとえば「藤が丘」には、市バス停と地下鉄駅の候補があります。地下鉄駅を指定するには、`--subway` を付けるか、`藤が丘(名古屋市地下鉄)` のような具体的な候補名を使ってください。

交通手段の指定は、出発地・到着地・経由地の候補と、経路に含まれる乗車区間の両方に適用します。`--bus` だけなら市バスのみ、`--subway` だけなら地下鉄のみが対象です。両方を指定した場合と、どちらも指定しない場合は、市バスと地下鉄の両方を対象にします。

経由地は `--via` で指定します。`--slow-transfer` はゆっくり乗換の条件で検索し、`--details` はのりばや区間運賃などの詳細を表示します。

## 検索日時と到着時刻

検索日時は日本時間の暦日時として扱います。`--at` には `HH:MM` または `YYYY-MM-DDTHH:MM` を指定できます。日付を省略した場合は今日の日付を使い、過去の時刻でも翌日へ繰り越しません。

たとえば10月5日の23時に `--at 01:00` を指定すると、10月5日の01時として検索します。翌日を調べる場合は日付も指定してください。時刻表の営業日境界は、経路検索の日付補完には適用しません。

`--arrive` を指定すると、指定時刻までに到着する経路を検索します。時刻を省略すると現在時刻を使います。`--first` は始発、`--last` は終発を検索します。`--first` と `--last` は互いに同時指定できず、どちらも `--at` や `--arrive` と組み合わせることはできません。

## 検索結果

有効な検索条件で経路が0件なら、成功として扱います。結果に含まれる乗換回数は、交通機関を降りて別の便・列車に乗り換える回数です。一つの交通機関に乗って移動する乗車区間の数とは区別します。

出力形式とエラーの扱いは、`nkotsu docs show output` で確認できます。
