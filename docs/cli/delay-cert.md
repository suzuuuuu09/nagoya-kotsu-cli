# 延着証明書

`delay-cert` は交通局が公開している延着証明書の一覧を取得します。現在の遅延状況ではありません。現在の運行状況は `nkotsu status` で確認してください。

```sh
nkotsu delay-cert
nkotsu delay-cert --line 東山線
nkotsu delay-cert --date 2026-09-08 --limit 5 --json
```

## 検索条件

| オプション | 指定すると変わる内容 |
| --- | --- |
| `--line <LINE>` | 路線名で絞り込む |
| `--date <YYYY-MM-DD>` | 証明対象の暦日で絞り込む |
| `--limit <N>` | 表示件数を1件以上で指定する。省略時は全件 |

路線名は既知の地下鉄路線名とAPI内の路線名から、前後空白除去・NFKC正規化後の完全一致、部分一致の順で選びます。複数候補は `ambiguous`、存在しない路線名は `not_found`、終了コード3です。「名城線」「名港線」は「名城線・名港線」に部分一致し、結果の路線名も「名城線・名港線」のままです。

有効な路線・日付に証明書がなければ正常な0件で終了コード0です。日付は実在する暦日の `YYYY-MM-DD` で指定します。営業日や記事作成日時と混同しません。路線・日付で絞った後、証明対象日時の降順に並べ、件数を制限します。APIの配列順を最新順とは仮定しません。

## 出力と失敗

Human出力は証明対象日、路線、タイトル、最大遅延、公式証明書のURLを表示します。最大遅延は「10分」「60分以上」などの文字列を保持し、数値に変換しません。

`--json` の `data` はAPI取得日時 `fetched_at` と一覧 `certificates` を持ちます。各証明書は `line`、`date`、`title`、`max_delay_time`、`url` を持ち、内部の証明書IDは直接出しません。

証明対象日時を解析できない証明書は除外し、正常な証明書を返します。除外範囲を `errors` に記録し、`complete: false`、終了コード5になります。全件不正でも空の一覧とエラーを返し、正常な0件と区別します。日時を推測して補いません。API全体の取得・解析失敗は全体失敗として扱います。

一覧は毎回取得し、永続キャッシュしません。`--raw` は取得URLをキー、本文を文字列とするオブジェクトです。詳細は `nkotsu docs show output` を参照してください。

証明書が古い・0件であることから、現在は正常運行であるとは判断しません。現在の遅延時間・列車位置も推定しません。証明書の新規発行やPDF生成は行いません。
