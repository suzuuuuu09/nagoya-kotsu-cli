# 普通運賃

`fare <FROM> <TO>` は料金検索用の駅マスターと経路データから普通運賃を取得します。経路検索の時刻・乗換条件による検索とは別の機能です。

```sh
nkotsu fare 藤が丘 名古屋
nkotsu fare 藤が丘 名古屋 --json
nkotsu fare 藤が丘 名古屋 --route 東山線
```

## 駅と料金経路

名前は前後空白除去とNFKC正規化後の完全一致を優先し、完全一致がなければ部分一致を使います。駅名は料金検索専用のマスターで解決します。同名の他社施設には路線名が付いている場合があります。

既定では料金経路をすべて返します。`--route <ROUTE>` は経路名で絞り込みます。駅や経路の候補が複数なら `ambiguous`、指定名がなければ `not_found`、終了コード3になります。先頭の経路を最短・通常・推奨と扱わず、最安を推奨と意味付けしません。

両駅が存在しても料金経路が提供されていなければ、正常な0件として終了コード0を返します。同駅間も0円とは推測しません。

## 出力と欠落

`--json` の `data` は `from`、`to`、`routes` を持ち、各経路は `name` と `fare_yen` を持ちます。内部の駅ID・料金区分ID・距離は含みません。普通運賃が欠落・不正な経路は `fare_yen: null` で残し、他の正常な運賃も保持します。この場合は `complete: false`、終了コード5とし、`errors` に欠落範囲を返します。

`--raw` は駅マスター・到着駅対応・経路セットの取得URLごとに、本文を文字列として返します。静的料金データの既定キャッシュ期間は24時間です。再検証には `--refresh`、永続キャッシュの読み書きを無効化するには `--no-cache` を指定します。詳細は `nkotsu docs show output` を参照してください。
