# 定期券料金

`pass <FROM> <TO>` は料金経路ごとの定期券料金を取得します。表示料金は料金データに基づくもので、購入資格を保証しません。通学証明や発売条件、利用者への券種の適用は判定しません。

```sh
nkotsu pass 藤が丘 名古屋
nkotsu pass 藤が丘 名古屋 --type 大学生 --months 1
nkotsu pass 藤が丘 名古屋 --with-bus --json
```

## 検索条件

| オプション | 指定すると変わる内容 |
| --- | --- |
| `--route <ROUTE>` | 料金経路名で絞り込む |
| `--type <TYPE>` | APIの券種名で絞り込む。固定された券種一覧ではない |
| `--months <MONTHS>` | 1・3・6か月のうち指定期間だけを表示する |
| `--with-bus` | 市バス併用用の定期料金区分を使用する |

駅と経路の名前解決は `fare` と共通です。既定ではすべての料金経路・券種・期間を表示します。先頭の経路を最短・推奨と扱いません。両駅が有効でも料金経路がなければ正常な0件です。

券種は対象となる全経路の券種名をまとめ、前後空白除去・NFKC正規化後の完全一致、部分一致の順で一度だけ解決します。複数候補は `ambiguous`、存在しない指定は `not_found`、終了コード3になります。例えば「大学生」は「学生定期券（大学生）」への部分一致として使えます。

## 部分失敗

同じ料金区分は一度だけ取得します。一部の取得が失敗しても正常な料金を保持し、取得できなかった経路は `types: []` で残します。全区分の取得が失敗しても経路を残します。`--with-bus` の区分対応がない場合も対象経路を残し、`not_found` を記録します。通常区分へのフォールバックはしません。

一期間の料金が欠落・不正なら、その期間だけを `prices` から除外します。正常な期間と券種名を残し、全期間が不正でも券種名を `prices: []` で残します。

券種候補を取得しきれない場合は、確認できた完全一致だけを使用します。完全一致がなければ部分一致で選ばず、全経路を `types: []` で残します。未取得の候補に指定券種がある可能性があるため、`not_found` とは断定しません。具体的な券種名を指定するか、取得失敗を解消して再実行してください。

部分失敗は `complete: false`、非0終了で欠落範囲を返します。価格の欠落・不正は終了コード5です。料金経路セット自体を取得できない場合は全体失敗になります。

## 出力

`--json` の `data` は `from`、`to`、`routes` を持ちます。経路の `types` に券種名 `name` と料金一覧 `prices` があり、各料金は `months` と `yen` を持ちます。内部IDや購入資格を表す項目は含みません。

Human出力は購入資格の注意を表示します。`--quiet` でこの注意を省略しても結果・エラー・欠落警告は残します。`--json` に注意文は混在しません。

`--raw` は料金検索に使った駅マスター・到着駅対応・経路セット・定期料金と、必要な場合だけ市バス併用区分対応をURLごとの本文文字列で返します。料金データは既定24時間キャッシュします。共通の出力・キャッシュ仕様は `nkotsu docs show output` を参照してください。
